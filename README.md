# 📚 Adler Catalog

> 🚧 **Em construção** — ainda antes da primeira versão (`v0.1.0`). O projeto está na fase de documentação e fundamentos, sem código de aplicação ainda.

## 🧐 O que é?

Um catálogo bibliográfico público para explorar as listas de leitura recomendadas em ***How to Read a Book***, de Mortimer J. Adler (edições de 1940 e 1972) — permitindo descobrir, pesquisar e relacionar autores, obras e recomendações com fidelidade às fontes históricas.
