# Functional Requirements — Adler Catalog

**Status:** Draft  
**Version:** 0.1  
**Scope:** V1 — Public Catalog
## 1. Collections
- **RF-001:** The system must allow visitors to list available bibliographic collections.
- **RF-002:** The system must allow visitors to view the numbered entries of a collection in their original order.
- **RF-003:** The system must preserve the original numbering and text of each collection entry.
## 2. Authors
- **RF-004:** The system must allow visitors to browse authors associated with a collection.
- **RF-005:** The system must allow visitors to view an author's details and associated works.
## 3. Works
- **RF-006:** The system must allow visitors to browse cataloged works.
- **RF-007:** The system must allow visitors to view a work's bibliographic information and authors.
- **RF-008:** The system must support works with multiple authors or without identified authors.
## 4. Recommendations
- **RF-009:** The system must allow visitors to view the works and work groups recommended by each collection entry.
- **RF-010:** The system must distinguish individual recommendations from work-group recommendations.
- **RF-011:** The system must preserve recommendation qualifiers, such as "especially".
- **RF-012:** The system must indicate which authors and recommendations carry source markers.
## 5. Discovery
- **RF-013:** The system must allow visitors to search for authors and works by name or title.
- **RF-014:** The system must allow visitors to filter works by author.
## 6. Out of Scope — V1
- User authentication and accounts.
- Personal reading lists.
- Reading progress tracking.
- Ratings and reviews.
- Book editions and ISBN management.
- Public administration interface.
